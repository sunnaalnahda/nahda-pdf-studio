# المعمارية الفنية — Nahda PDF Studio

## قرار المعمارية

**Local-first, port/adapter، بدون backend في المرحلة الأولى.** Flutter/Dart ينجز كافة عمليات فتح وتحرير وحفظ مستندات المستخدم، بما فيها الويب وأندرويد. Python أداة منفصلة للمطور على Windows وCI، **لا** يعمل داخل المتصفح ولا في APK. لن نبني REST API أو خادم FastAPI في هذه المرحلة.

```text
Flutter UI — NahdaTheme + WorkspacePage + AR/EN RTL
                │
                ├── PdfEditingEngine (abstract contract)
                │       └── DartPdfEngine (dart_pdf_editor 15.0.0)
                │               └── pdf_document / pdf_cos (incremental changes)
                │
                ├── Pdfrx / PDFium — independent accurate preview
                │
                └── PdfFileRepository (abstract contract)
                        └── LocalPdfFileRepository (file_picker 13.3.3)

QA only, outside the app:
Python 3.13 → pypdf + PDFium renderer → structural/visual QA report
                             └── optional pikepdf (qpdf validation)

Original PDF (immutable in application) → in-memory revision → Save As PDF
```

## مسؤوليات كل جزء

| الطبقة | المسؤولية | تعمل على الجهاز النهائي؟ |
|---|---|---|
| Flutter Widgets | عناصر الواجهة، RTL، الإدخال، التبديل بين المحرّر والمعاينة | الويب وأندرويد |
| Dart engine adapter | إدخال FreeText عربي، التراجع، التعديلات التدريجية وإعادة التحميل | الويب وأندرويد |
| PDFium/pdfrx | رندر، تكبير، تحديد/بحث ضمن حدود العارض | الويب وأندرويد |
| FilePicker adapter | فتح ملف محلي، وإعطاء المستخدم نسخة محفوظة | الويب وأندرويد |
| Python QA | مقارنة البنية، النصوص المستخرجة، الرسم، مراقبة الرجوع للتصوير | جهاز المطور وCI فقط |
| Python pikepdf (اختياري) | تحقيق / إصلاح بنية PDF خارج التطبيق | جهاز المطور فقط |

## تحرير النص الأصلي

يوجد فرق جوهري بين ثلاث عمليات:

1. **FreeText annotation:** إضافة نص حقيقي بخط متجه وقابل للتعديل على الصفحة، دون تغيير stream الكتابة الأصلي؛ هذه العملية منجزة في مصدر المرحلة الأولى وخاضعة لاختبار نهائي على Flutter.
2. **استبدال كلمة موجودة داخل PDF:** قد يحتاج إعادة ترميز `Tj/TJ` وخريطة ToUnicode وتوافق subset font والمواضع، وإذا لم تتوفر glyphs أو كان النص مرسومًا كمسارات فلا يمكن دائمًا ضمان التطابق. يدعم المحرك الأساسي بعض مسارات الاستبدال لكن **لم ننفذ ولم نعتمد هذه الميزة للمستخدم بعد**.
3. **OCR:** يحدد محتوى الصورة ويضيف طبقة بحث وقد تحتاج ترجمة اتجاه؛ لا يعيد النص الأصلي المتجه من العدم، ويحتاج معالجة مختلفة للويب وأندرويد. لاحقًا: Tesseract على Android محليًا، ووضع تحويل على سطح المكتب منفصل إن لزم؛ Web OCR باستخدام WASM يدرس بعد قياس الذاكرة/الحجم.

## لماذا محركا عرض/تحرير؟

التحرير باستخدام مكتبة Dart المحمولة يتيح تعديلات محلية على نفس الكود في Web وAndroid. PDFium يوفّر **معاينة مستقلة** لتقييم جودة ما تم حفظه مقابل محرر Dart، ويحد من الاعتماد على نتيجة محرك واحد. الاختلاف بين العارضين ليس إثبات جودة؛ أي اختلاف ملحوظ في حروف العربية أو الخطوط يجب أن يمنع الإصدار قبل التحقيق.

## مراحل التطوير

- **0.1 — التأسيس:** الواجهة، فتح/عرض PDF، FreeText عربي، Save As، QA بنيوي، CI.
- **0.2 — التحقق من الجودة:** فتح/حفظ وإعادة فتح على Chrome وAndroid، تحسين RTL واختيار موضع النص واللون والخط، معالجة الملفات التالفة والمحمية، توقيعات PDF.
- **0.3 — إدارة الصفحات:** دمج، قص، تدوير، إعادة ترتيب، تصدير نطاقات، مع اختبارات فقد الروابط والخطوط والنماذج.
- **0.4 — تحرير النص الأصلي المشروط:** دعم الحالات الموثوقة فقط، كشف unsupported content، اختبار PDF/A/CMYK/fonts وصيغ ToUnicode والشكل المقارن.
- **0.5 — OCR عربي دون خادم:** اختبارات Tesseract وWASM وتحديد حدود الذاكرة مع الموافقة الصريحة.
- **1.0 — جاهزية إصدار:** مراجعة تراخيص كل transitive dependency، قياس أداء على هواتف متوسطة، نشر HTTPS ثابت/PWA، توقيع APK، فحص الملفات الحساسة.

## مبادئ السلامة

- لا رفع للملفات ولا تتبع ولا قاعدة بيانات ولا اعتماد خادم PDF.
- حفظ نسخة بدل overwrite، وحد 80MB لفتح الملف في الذاكرة (ليس حدًا كافيًا للملفات المضغوطة الخبيثة).
- لا ترسل مستندات سرية إلى سجلات اختبار CI العامة؛ الاختبارات تعتمد ملفات مولّدة.
- لا ننفذ JavaScript أو إجراءات مضمنة في PDF ضمن المحرّر من تلقاء أنفسنا، ويفضل رفض الروابط الخطرة في إصدار لاحق.
- توقيع PDF الرقمي يمكن أن يصبح غير صالح بعد أي تعديل؛ يلزم تحذير/فحص قبل إتاحة تحرير المستندات الموقعة.
